DrawingAnalysisMiya v2.0.0 - 2D機械図面 解析・見積り・部材表作成ツール

2Dの機械図面（PDF形式または画像形式）をAIが解析し、部品ごとの数量を反映した体積・重量計算、概算材料費、搬送時の推奨トラック選定、切断寸法入りの部材表・定尺発注集計、使用購入品・使用機械加工品の手配リストを自動作成するWindows専用デスクトップアプリケーションです。
解析結果は印刷設定済みの新規Excelブックとしてワンクリックで開けるため、そのまま印刷したり、必要な場合だけ任意の場所へ保存したりできます。
最新のAIサービス（Gemini API および Azure OpenAI Service）に対応しており、用途や利用環境に合わせて柔軟にAIエンジンを切り替えてご利用いただけます。

アプリの概要と機能

1. PDF（複数ページ対応）/ 画像ファイルと拡大プレビュー
PDFの図面ファイルや、PNG・JPEG・BMPなどの画像ファイルを直接読み込むことができます。複数ページのPDFでは解析したいページを選んで切り替えられ、ファイル選択直後に図面プレビューが表示されます。プレビューをクリック（または「拡大表示」ボタン）すると、マウスホイールで拡大・縮小やドラッグ移動ができる専用ビューアーで図面の細部を確認できます。

2. 実務に直結する4つの解析項目と「見積り・搬送サマリー」
画面左側の「解析項目の選択」チェックボックスで、解析したい情報を自由に組み合わせて実行できます。
・体積・重量・搬送: 三面図から各部品の構成要素・寸法・数量・全体外形寸法を読み取り、1個あたり重量と数量掛け小計重量、製品全体の総重量を自動計算します。
・部材表・切断寸法: 工場への切断指示や鋼材手配に使える部材表（部材種別・材質・断面規格/板厚・切断寸法・端部切断形状・数量・合計切断長さ・小計重量・表面処理）を自動生成します。
・使用購入品: ボルト・ナット・ベアリング・Oリング・シリンダなどの市販品やJIS規格品について、品名・メーカー・型式・仕様・数量・単位・手配区分を抽出し、発注手配しやすく一覧化します。
・使用機械加工品: 切削・旋盤・フライス・穴あけ・研削・溶接後加工などが必要な製作部品について、材質・素材寸法・加工工程・公差/粗さ・熱処理/表面処理・数量を抽出します。
・見積り・搬送サマリー: 解析結果から以下を自動集計・判定します。
  - 製品最大外形寸法（最大長さ L × 最大幅 W × 最大高さ H）: 画面右側の常時表示バー・サマリー画面・Excelシートに製品の最大長さ・最大幅・最大高さをひと目で確認できるよう表示します。
  - 搬送トラック選定: 総重量・全体外形寸法（L×W×H）・最大長尺部材から推奨トラック車種（軽トラ / 1.5t / 2t標準 / 2tロング / 4t標準 / 4tロング / 10t大型等）とユニック・フォークリフト等の荷役目安を自動提示します。
  - 材質別 重量集計 ＆ 概算材料費: 材質ごとの合計重量と概算材料費を自動算出します。「単価設定・再計算」ボタンから材質別単価（円/kg）を変更すれば、AI再通信なしで即座に再計算できます。
  - 鋼材・定尺発注集計: 同じ断面規格・材質の鋼材を自動名寄せし、合計切断長さとロス10%見込みでの5.5m / 6.0m定尺必要本数目安を算出します。

3. 選べるAIエンジンと充実した詳細設定
・Gemini API（無料枠 / 課金枠）: Googleの最新AIモデルを活用し、無料枠・課金枠それぞれに独立したAPIキーやモデル、リクエスト制限（RPM / スレッド数）を設定して切り替えられます。
・Azure OpenAI Service（法人・セキュア環境向け）: Microsoft Azure上の企業向けOpenAIモデル（次世代 v1 API および従来の日付バージョン両対応）を利用し、入力データが外部のAI学習に利用されない環境で社外秘の図面も安心して解析できます。
・最新モデル自動取得と自動最適化: 「最新モデルを更新」を押すと最新モデル一覧の取得と同時にパフォーマンス設定や抽出パラメータも自動最適化されます。
・カスタムプロンプトとお気に入り保存: 独自の追加指示をチェックボックス形式で管理でき、よく使う指示はお気に入りとして保存し、全タブ共通で再利用できます。

4. 印刷設定済みの新規Excelで直接開く・コピー・並べ替え
解析結果は画面右側の5つのタブで切り替えながら確認できます。表を右クリックすると「選択行をコピー」や「表全体をコピー」でそのまま貼り付けでき、列見出しのクリックで昇順・降順に並べ替えできます。
「📊 Excelで開く」ボタンを押すと、見積り・搬送サマリーや部材表・購入品手配表などをシート分けした新規の未保存Excelブックが直接開きます。全シートにあらかじめ以下の印刷設定が適用されているため、開いてそのまま美しく印刷でき、残したい場合だけExcel上で任意の名前を付けて保存できます。
・A4横向き・横幅1ページ自動収縮（縦は行数に応じて自動改ページ）
・2ページ目以降もレポートタイトルと表見出しを自動繰り返し印刷
・図面名・印刷日・ページ番号・シート名のヘッダー/フッター自動付与
・折り返し設定と行高の自動調整・罫線・合計数式（SUM）入り

5. わかりやすいリアルタイム進捗表示と解析の中止機能
解析の実行中は、画面左下の進捗パネルに現在の処理フェーズ・プログレスバー・進捗率（%）・経過時間（分:秒）がリアルタイムで表示されるため、処理状況をひと目で把握できます。途中で止めたい場合も「解析を中止」ボタンを押すことで安全に処理を中断できます。

動作環境

・OS: Windows 10 / Windows 11（64bit）
・Microsoft Excel（新規ブックで直接開いて確認・印刷する場合に推奨）
・インターネット接続環境（AI解析に必須）
・以下のいずれかのAIサービス利用情報
  - Gemini API キー（Google AI Studioから無料で取得可能です）
  - Azure OpenAI Service の接続情報（エンドポイントURL、APIキー、デプロイ名）

インストール・実行方法

特別なインストール作業は不要です。以下の手順ですぐにお使いいただけます。

1. 配布された DrawingAnalysisMiya-v2.0.0.exe などの実行ファイルを任意のフォルダに保存します。
2. ファイルをダブルクリックして起動します。

初回起動時の警告画面（SmartScreen）について

本ソフトを初めて起動する際、Windowsのセキュリティ機能（Windows Defender SmartScreen）によって「Windows によって PC が保護されました」という青い警告画面が表示される場合があります。
これはアプリの不具合やウイルスではなく、新しく作成された個人・社内向けアプリで表示される標準的な確認画面です。以下の手順で安心して起動してください。

1. 警告画面内にある「詳細情報」という文字をクリックします。
2. 右下に新しく現れる「実行」ボタンをクリックします。
（2回目以降はこの画面は表示されず、すぐに起動するようになります）

基本的な使い方

1. AI / API の設定を行う
・画面左上の「AI / API 設定」から、使用するAIサービス（Gemini 無料 / Gemini 課金 / Azure OpenAI）を選びます。
・「⚙️ AI詳細設定 (APIキー / モデル)」ボタンを押して詳細設定画面を開きます。
・該当するタブにAPIキー（Azure OpenAIの場合はエンドポイントURL・APIキー・デプロイ名）を入力し、「接続テスト」ボタンで通信が正常か確認します。
・「設定を適用して保存・閉じる」ボタンを押すと設定が自動保存され、メイン画面のステータス表示が「設定済み ✅」に変わります。

2. 図面ファイルと解析項目を選択する
・「ファイルを選択」ボタンをクリックし、解析したい2D機械図面のファイル（PDFまたは画像）を選びます。選択するとすぐに右上にプレビューが表示されます（複数ページのPDFは「対象ページ」からページを切り替えられます）。
・「解析項目の選択」で解析したい項目にチェックを入れ、必要に応じて「基本比重（g/cm³）」や「基本単価（円/kg）」を調整してください。変更した値は「💾 比重・単価を保存」ボタン（または入力欄の確定）で設定ファイルへ保存され、次回起動時にも引き継がれます。

3. 解析を実行する
「解析を実行」ボタンをクリックします。画面左下の進捗パネルに処理フェーズ・プログレスバー・進捗率（%）・経過時間がリアルタイムで表示され、完了すると右側の各タブに結果と「見積り・搬送サマリー」が表示されます。途中で止めたい場合は「解析を中止」ボタンで中断できます。

4. 単価調整・Excelで開いて印刷 / 任意保存を行う
・「見積り・搬送サマリー」タブの「単価設定・再計算」ボタンから材質ごとの単価（円/kg）を自由に調整して見積り金額を即再計算できます。
・「📊 Excelで開く」ボタンを押すと、印刷設定済みの新規Excelブックが開きます。そのまま印刷するか、必要に応じてExcelの「名前を付けて保存」で任意のフォルダへ保存してください。
